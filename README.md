# Naïades Tattoo

Astro + Keystatic implementation of the Naïades Tattoo website.

## Deployment

- Public site: GitHub Pages, repository spelcc/naiades
- Editor: https://naiades.irz.fr/keystatic on Cloudflare Workers
- Content and uploaded media are committed to GitHub by Keystatic

## Local development

Install with npm install, then run npm run dev. Keystatic is available at /keystatic.

## Checks

Run npm run check, npm test and npm run build:pages.
